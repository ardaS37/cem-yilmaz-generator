# Cem Yılmaz Miim Editörü

Fotoğrafı, alt yazıyı ve renk efektlerini masaüstü arayüzünden düzenleyip PNG olarak kaydetmek için küçük bir Python uygulaması.

## Çalıştırma

```bash
python -m pip install -r requirements.txt
python main.py
```

## Özellikler

- Kendi fotoğrafını seçme
- Alt yazıyı anında değiştirme
- Mavi, kırmızı veya seçilen başka bir renk ile tint katmanı
- Katman opaklığı, parlaklık, kontrast, doygunluk, bulanıklık ve keskinlik ayarları
- Tüm görseli yatay/dikey sıkıştırma veya genişletme, girdap, negatif renk ve aşırı parlama efektleri
- Sepya, posterleştirme, pikselleştirme, kenar çizgileri, film greni, RGB kayması, vinyet, tarama çizgileri, kabartma ve yatay ayna
- Canlı önizleme ve PNG dışa aktarma

Varsayılan ayarlar, referanstaki gibi mavi ve hafif desatüre bir haber/meme görünümü verir.
